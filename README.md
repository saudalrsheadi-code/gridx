# GRID X | جريد اكس

منصة للإدارة والتشغيل والمحاسبة لمؤسسات تشغيل وصيانة شبكات التوزيع الكهربائية: المستخلصات والتحصيلات، والمصروفات والسداد، والشركاء ومساهماتهم، والقيود المحاسبية والتقارير، والمرفقات، وتبادل Excel، والنسخ الاحتياطي، والإلغاء بقيد عكسي.

**الموقع:** https://saudalrsheadi-code.github.io/gridx/

## البيانات

- النسخة المنشورة **تبدأ فارغة**. لا يحتوي المستودع ولا الموقع أي بيانات مستخدم أو نسخ احتياطية أو مرفقات.
- بيانات كل مستخدم تُحفظ **في متصفحه على جهازه فقط** (localStorage وIndexedDB)، ولا تُرسل إلى أي خادم، ولا يراها غيره.
- لنقل البيانات إلى جهاز آخر: «تصدير نسخة احتياطية» ثم «استعادة من نسخة» على الجهاز الآخر. التفاصيل في [دليل الاستخدام](usage.html).
- لا يوجد تسجيل دخول؛ الأدوار تغيّر الواجهة فقط.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | المنصة (ملف واحد؛ المكتبات من cdnjs وjsDelivr) |
| `usage.html` | دليل الاستخدام وحفظ البيانات |

الشيفرة تتضمن مولّد بيانات اختبار افتراضية يستخدمه «الفحص الذاتي» داخل الذاكرة فقط؛ لا يُحفظ ولا يظهر في بيانات المستخدم.
